## HOW TO USE THIS INDEX

This is not a wiki. This is a filing system. Each entry points to where information lives. Information may exist in multiple files — when it does, the files may contradict each other. That is accurate to the world. Cross-reference. Check your sources. Trust nothing completely.

**Search by topic.** If you need to know about a subject, find it below. The primary source is listed first, secondary sources follow.

**Search by entity.** Corponations, characters, locations, and technologies are indexed separately.
