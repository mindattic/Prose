# Gospel: History vs. Heritage (GSPL) — Master Entity Seed Catalog

Extraction pass across Matthew, Mark, Luke, and John. Organized as: **Persons** (narrative
figures → supernatural entities → alias key → same-name disambiguation → genealogical-only
condensed lists → referenced-but-offstage OT figures), then **Places**. Ordering follows first
canonical appearance: everything new in Matthew appears first (in Matthew's internal order),
then everything new to Mark, then new to Luke, then new to John — with a single merged entry
per figure/place noting every book it appears in.

This is the **seed list** for entity creation (Step 2 of the New Story Workflow, applied to
GSPL) — extraction from the text itself, not yet the citation-grounded historical/biographical
detail each entity will carry once drafted (that's a separate pass per entity, same discipline
as `pontius-pilate.md`/`twelve-apostles.md`).

**Summary counts:** ~65 narrative persons (including apostles, family, rulers, and named minor
figures), 2 named supernatural entities, ~65 genealogical-only names across the two
genealogies, 16 referenced-only OT figures, and ~50 places. The disambiguation guide
(Section III) is the highest-priority read before entity seeding begins — six "Simons,"
four-to-five "Marys," three "Judases/Jameses/Johns," and three overlapping "Philips"/"Herods"
are the main collision risks for a fiction-engine-style entity table.
